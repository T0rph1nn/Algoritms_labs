# Диаграмма потоков данных в ХД

```mermaid
flowchart LR
    Ecommerce[Интернет-магазин] -->|заказы, корзины, оплаты, просмотры| ETL[ETL]
    Mobile[Мобильные приложения] -->|заказы, события приложения, push-реакции| ETL
    CRM[CRM] -->|клиенты, сегменты, обращения, коммуникации| ETL
    WMS[WMS] -->|остатки, приемка, отгрузка, перемещения| ETL
    OneCTrade[1C Торговля] -->|номенклатура, цены, продажи, возвраты| ETL
    OneCSD[1C SD] -->|сервисные заявки и SLA| ETL
    OneCDocs[1C Документооборот] -->|договоры, поставщики, статусы документов| ETL
    System[Внутренняя система] -->|справочники и операционные события| ETL
    BrandAnalytics[BrandAnalytics] -->|упоминания, тональность, темы отзывов| ETL

    ETL --> Staging[Staging]
    Staging --> DWH[ХД]
    DWH --> SalesMart[Витрина продаж]
    DWH --> CustomerMart[Витрина клиентов]
    DWH --> InventoryMart[Витрина запасов]
    DWH --> SocialMart[Витрина соцмедиа]
    DWH --> ForecastMart[Витрина прогнозов]

    SalesMart --> BI[BI]
    CustomerMart --> BI
    InventoryMart --> BI
    SocialMart --> BI
    ForecastMart --> BI
```

## Какие данные можно анализировать

- Объемы покупок через интернет-магазин, мобильное приложение и офлайн-магазин.
- Динамику продаж по товарам, категориям, регионам, каналам и периодам.
- Остатки товаров, скорость оборачиваемости и риск дефицита.
- Эффективность CRM-коммуникаций и повторные покупки.
- Отзывы и упоминания продукции в соцмедиа через BrandAnalytics.
- Связь между негативными отзывами, возвратами, сервисными заявками и падением продаж.
- Прогноз закупок исходя из спроса, текущих остатков, сезонности и внешнего интереса к продуктам.
